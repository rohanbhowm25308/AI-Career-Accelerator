##  About the Project

**AI Career Accelerator** takes a single resume and builds a complete, actionable career plan around it — scoring it against real job descriptions, running a mock interview on your actual skills, mapping out what to learn next, and matching you to internship tracks worth applying to.

---

##  Core Modules

| Module | What it does |
|---|---|
| 🔍 Resume Analyzer | ATS score + JD match score with a full category breakdown |
| 🎤 AI Mock Interview | Interview questions generated from your real detected skills |
| 🗺️ Skill Roadmap | Skill gaps turned into a phased learning plan |
| 🎯 Internship Matcher | Weighted matching against real early-career tracks |
| ➕ 29 more modules | Recruiter simulation, eye-tracking heatmaps, resume comparison, salary prediction & more — 33 AI modules total |

---

##  Tech Stack

**Backend:** Python, Flask, scikit-learn, pdfplumber, python-docx, ReportLab
**Frontend:** HTML, CSS, vanilla JavaScript
**Gen AI (optional):** Anthropic Claude API
**Deployment:** Gunicorn on Render

##  Run It Locally

```bash
git clone https://github.com/rohanbhowm25308/AI-Career-Accelerator.git
cd AI-Career-Accelerator
pip install -r requirements.txt
python app.py
```

Open **http://127.0.0.1:5000** — no setup required.

To enable real Gen AI suggestions:

```bash
export ANTHROPIC_API_KEY=your-key-here
python app.py
```
